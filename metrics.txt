#
# This file lists all Prometheus metrics exposed by the Voice AI system.
#
# Coverage includes:
# - PCM audio pipeline (VAD, AGC, AEC, jitter buffer, transcoding)

# - TTS streaming pipeline
# - Evaluation engine scoring
# - Session lifecycle management
# - Circuit breakers, rate limiting, bulkheads
# - Kafka, Redis, Mongo integrations
# - Controller (PTT, interrupts, pipeline control)
# - System-level process metrics
#
# Exported via: http://app:8000/metrics
# Scraped by: Prometheus
#
# Total metrics: ~600+
#
# ============================================================
